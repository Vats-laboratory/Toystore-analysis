Toy Store E-Commerce Analytics
==============================

Business Objective
------------------
Analyze the company's e-commerce funnel to understand how
customers are acquired, how effectively sessions convert into
orders, which products drive commercial performance, and how
customers behave after their initial purchase.

Key Business Questions
----------------------

Acquisition
- Which traffic sources generate the most sessions?
- Which campaigns/content generate the most traffic?
- How does acquisition differ by device?

Conversion
- What is the session-to-order conversion rate?
- Which traffic sources convert best?
- Does conversion differ by device?
- Does device type change the relationship between acquisition
  source and conversion?

Commercial Performance
- Which products generate the most revenue and profit?
- Which products are ordered most frequently?
- Which products have high return rates?
- Which products have strong/weak margins?

Retention
- How frequently do customers make repeat purchases?
- How long does it take customers to return?
- Which factors are associated with repeat purchasing?
- Is return behavior associated with subsequent retention?
